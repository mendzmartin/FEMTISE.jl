# Citing and contact

## Citing

If `FEMTISE.jl` contributes to your research, please cite the package and the
version you used (the version is listed in your project's `Manifest.toml`):

```bibtex
@misc{Mendez2024FEMTISE,
  author    = {Mendez, Martin},
  title     = {{FEMTISE.jl}: a {Julia} package for the time-independent
               {Schr\"odinger} equation by the finite element method},
  year      = {2024},
  version   = {0.1.1},
  publisher = {GitHub},
  url       = {https://github.com/mendzmartin/FEMTISE.jl}
}
```

Publications that used the package:

- M. Mendez and F. M. Pont, *Dynamics of correlations and entanglement generation in
  electron-molecule inelastic scattering*, Phys. Rev. A **111**, 052411 (2025).
  [doi:10.1103/PhysRevA.111.052411](https://doi.org/10.1103/PhysRevA.111.052411)

## Contact and contributions

- Questions, bug reports and feature requests:
  [GitHub issues](https://github.com/mendzmartin/FEMTISE.jl/issues).
- Contributions are welcome as pull requests. Please add a test that checks the new
  behavior against an analytic or independently computed reference, and an entry in
  the *Unreleased* section of `CHANGELOG.md`.
- Maintainer: [Martín Mendez](mailto:martinmendez@unc.edu.ar).
