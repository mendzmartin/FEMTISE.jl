Eigenvalue problem

FEMTISE.eigen_problem — Method
eigen_problem(weakform_k,weakform_m,test,trial; <keyword arguments>)

Aim

  • Define eigen problem as an input to solve function where we compute eigen problem by Arpack eigs function.

Arguments

  • weakform_k::Function: forma bilineal lado izquierdo de la formulación débil
  • weakform_m::Function: forma bilineal lado derecho de la formulación débil
  • test::FESpace: espacio de prueba, puede ser MultiFieldFESpace
  • trial::FESpace: espacio de solución, puede ser MultiFieldFESpace
  • nev::Int=10: número de autovalores requeridos
  • tol::Float64=10e-6: relative tolerance for convergence of Ritz values
  • maxiter::Integer=100: maximum number of iterations
  • explicittransform::Symbol=:none: shift and invert should be explicitly invoked in julia code
    • =:auto:
    • =:shiftinvert:
  • sigma::Float64=1.0: the level shift used in inverse iteration.
  • which::Symbol=:LM: eigenvalues of largest magnitude (default)
    • =:SM: eigenvalues of smallest magnitude
    • =:LR: eigenvalues of largest real part
    • =:SR: eigenvalues of smallest real part
    • =:LI: eigenvalues of largest imaginary part (nonsymmetric or complex matrix only)
    • =:SI: eigenvalues of smallest imaginary part (nonsymmetric or complex matrix only)
    • =:BE: compute half of the eigenvalues from each end of the spectrum, biased in favor of the high end. (real symmetric matrix only)

Returns

  • EigenProblem: problem definition

FEMTISE.eigen_values_and_eigen_vectors — Method
eigen_values_and_eigen_vectors(p₁,p₂,q,r,dΩ,USpace,VSpace; <keyword arguments>)

Aim

  • Compute matrix eigen problem and return eigenvalues and eigenvectors

Arguments

  • p₁,p₂,q,r::Function: functions from Sturm Liouville formulation
  • dΩ::Gridap.CellData.GenericMeasure: measure of FE grid
  • USpace::FESpace: trial FE Space
  • VSpace::FESpace: test FE Space
  • params::Tuple=(nev,tol,maxiter,explicittransform,sigma): params to Arpack eigs function.
    • nev::Integer=10: quantity of eigendata to calculate
    • tol::Float64=10e-9: relative tolerance for convergence of Ritz values
    • maxiter::Integer=100: maximum number of iterations
    • explicittransform::Symbol=:none: shift and invert should be explicitly invoked in julia code
    • sigma::Float64=1.0: the level shift used in inverse iteration.

Example

using Gridap
using FEMTISE
using LinearAlgebra

# Define functions
p₁(x)=1.0
p₂(x)=0.0
q(x)=0.0
r(x)=1.0
# Define measure
Ω=1.0:0.1:10.0
dΩ=Gridap.CellData.CellData(Ω)
# Define FE Spaces
USpace=fe_space(1,1,Ω)
VSpace=fe_space(1,1,Ω)
# Compute eigenvalues and eigenvectors
ϵ,ϕ=eigen_values_and_eigen_vectors(p₁,p₂,q,r,dΩ,USpace,VSpace)
source

FEMTISE.run_default_eigen_problem — Method
run_default_eigen_problem(simulation_data)

Run the simulation described by an input file and write its results to disk. simulation_data is the tuple returned by set_type_potential(path), where path is the input file without the .dat extension:

run_default_eigen_problem(set_type_potential("path/to/input"))

source
FEMTISE.input_data — Method
input_data(data_file_name)

Aim

  • Read the input file data_file_name * ".dat" of the input-file driver.

Format

  • Lines 1–21 are mandatory and are read by position (see the "Input file reference" page of the documentation): the value is the third whitespace-separated token of each line.
  • Optional lines after line 21 (since v0.2.0) are read by name, as key = value(s); lines starting with # are comments. Keys: masses, element_order, quadrature_degree, potential_data_file, interpolation, analysis_param_2, Lz, nz (see DriverOptions).

Arguments

  • data_file_name::String: name of the input file, without the .dat extension.

Returns

  • InputData1D, InputData2D or InputData3D.

Errors

  • Throws an ArgumentError describing the problem if the file is inconsistent.
source

FEMTISE.DriverOptions — Type
DriverOptions

Optional settings of an input file (lines after the 21 mandatory lines, introduced in v0.2.0). Default values reproduce the behavior of earlier versions.

Fields

  • masses: mass of each coordinate in units of the electron mass, or nothing (electron mass for every coordinate).
  • element_order: degree of the Lagrange elements (default 2).
  • quadrature_degree: degree of exactness of the quadrature (default 3).
  • potential_data_file: data file with a tabulated potential, or "".
  • interpolation: :linear or :cubic interpolation of the tabulated potential.
  • analysis_param_2: second swept parameter (AnalysisParam) or false.
  • Lz, nz: third side length and number of cells of 3D problems.

FEMTISE.solve_tise — Method
solve_tise(model, potential; masses = 1.0, order = 2,
           quadrature_degree = 2order + 2, nev = 10, sigma = 0.0,
           tol = 1e-10, maxiter = 1000, guard_states = 4,
           boundary_tags = "boundary")

Solve the time-independent Schrödinger equation

\[\Big[-\sum_k \frac{1}{2M_k}\frac{\partial^2}{\partial x_k^2} + V(\mathbf{x})\Big]\psi = \varepsilon\,\psi\]

on model (a Gridap mesh in 1, 2 or 3 dimensions) with $\psi = 0$ on the boundary, and return the nev eigenpairs closest to sigma as a TISESolution, sorted by energy.

Arguments

  • potential: function of the mesh point x (x[1], x[2], x[3]), e.g. a Julia function or a tabulated_potential.
  • masses: mass of every coordinate, or one mass per coordinate, in units of the electron mass (default: electrons).
  • order: degree of the Lagrange elements.
  • quadrature_degree: degree of exactness of the Gauss quadrature. The default integrates exactly potentials up to degree 2 (eigenvalues are upper bounds).
  • nev, sigma, tol, maxiter: settings of the shift-and-invert eigensolver.
  • guard_states: number of additional eigenpairs computed and discarded. Krylov eigensolvers can miss members of a degenerate level at the edge of the requested window; the extra states make the nev returned eigenpairs reliable.

Example

using FEMTISE, Gridap
model = CartesianDiscreteModel((-10.0, 10.0), (200,))
sol = solve_tise(model, x -> 0.5 * x[1]^2; nev = 5)
sol.energies          # ≈ [0.5, 1.5, 2.5, 3.5, 4.5]

FEMTISE.sweep_eigenvalues — Method
sweep_eigenvalues(model, potential, values1[, values2]; masses = 1.0, order = 2,
                  quadrature_degree = 2order + 2, nev = 10, sigma = 0.0,
                  tol = 1e-10, maxiter = 1000, guard_states = 4,
                  boundary_tags = "boundary")

Eigenvalues as functions of one or two potential parameters. potential(x, λ) (one parameter) or potential(x, λ, μ) (two parameters) is evaluated for every value in values1 (and values2). The mesh, measures and finite element spaces are built once and reused.

Returns a matrix energies[n, i] (one parameter) or an array energies[n, i, j] (two parameters) with the nev eigenvalues closest to sigma, in ascending order at every point.

Example

model = CartesianDiscreteModel((-10.0, 10.0), (200,))

FEMTISE.tabulated_potential — Method
tabulated_potential(path; interpolation = :linear, extrapolation = :error)
tabulated_potential(x, values; interpolation = :linear, extrapolation = :error)
tabulated_potential(x, y, values; extrapolation = :error)

Build a potential function from tabulated values, read from the data file path or given as arrays.

File formats

  • 1D: two columns, $x$ and $V(x)$, with $x$ strictly increasing.
  • 2D: three columns, $x$, $y$ and $V(x,y)$, containing every point of a regular (tensor-product) grid in any order.

Lines starting with # are comments.

Keyword arguments

  • interpolation: :linear (1D and 2D, bilinear in 2D) or :cubic (natural cubic spline, 1D only). Cubic splines are recommended for smooth potentials: their error decreases as $\Delta^4$ with the spacing $\Delta$ of the table, against $\Delta^2$ for linear interpolation.
  • extrapolation: :error (default) raises an error if the potential is evaluated outside the table, which usually means that the mesh is larger than the table; :flat uses the value at the nearest edge of the table.

Example

V = tabulated_potential("potential.dat"; interpolation = :cubic)
sol = solve_tise(CartesianDiscreteModel((-8.0, 8.0), (320,)), V; nev = 5)

Autocorrelation and spectra (v0.2.0)

FEMTISE.autocorrelation — Method
autocorrelation(coefficients, energies, t)

Autocorrelation $C(t) = \sum_n |c_n|^2 e^{-i\varepsilon_n t}$ (ħ = 1) at the times t (a number or a collection), from the expansion coefficients of the wave packet (see expansion_coefficients) and the eigenvalues.

$|C(t)|^2$ is the survival probability of the initial state.

source
FEMTISE.autocorrelation_spectrum — Method
autocorrelation_spectrum(coefficients, energies, ω; width, lineshape = :lorentzian)

Spectrum of the wave packet, $\sigma(\omega) = \sum_n |c_n|^2 L(\omega-\varepsilon_n)$, on the frequencies (energies) ω, with every line broadened by

  • lineshape = :lorentzian: $L(\Delta) = \frac{1}{\pi}\frac{w}{\Delta^2 + w^2}$ (half width at half maximum w);
  • lineshape = :gaussian: $L(\Delta) = \frac{1}{\sqrt{2\pi}\,w}e^{-\Delta^2/(2w^2)}$ (standard deviation w).

These are the Fourier transforms of $C(t)$ damped by $e^{-wt}$ and by $e^{-w^2t^2/2}$, respectively, so they coincide with fourier_transform of the sampled autocorrelation with the matching window. Each line has unit area, so $\int\sigma\,d\omega = \sum_n|c_n|^2$.

source
FEMTISE.expansion_coefficients — Method
expansion_coefficients(ψ₀, states, dΩ)

Coefficients $c_n = \langle\phi_n|\psi_0\rangle = \int \phi_n^*\,\psi_0\,d\Omega$ of the wave packet ψ₀ in the eigenstates states (e.g. sol.states of solve_tise). ψ₀ can be a Julia function of the mesh point or a finite element function.

$\sum_n |c_n|^2$ equals the norm of ψ₀ only if the eigenstates span it: check it to make sure that enough eigenstates were computed.

Note

Eigenvectors of a degenerate level are linearly independent but not necessarily orthogonal; in that case orthonormalize them before computing the coefficients.

source
FEMTISE.fourier_transform — Method
fourier_transform(t, C, ω; window = :none, width = 0.0)

Spectrum $\sigma(\omega) = \frac{1}{\pi}\,\mathrm{Re}\int_0^{T} C(t)\,w(t)\,e^{i\omega t}\,dt$ of an autocorrelation function sampled at equally spaced times t (starting at $t=0$), evaluated at the frequencies ω with the trapezoidal rule.

Windows

  • :none: $w = 1$. Lines have width $\sim\pi/T$ and side lobes.
  • :exponential: $w = e^{-\gamma t}$ with $\gamma =$ width. Lorentzian lines (HWHM $\gamma$); requires $\gamma T \gg 1$.
  • :gaussian: $w = e^{-\gamma^2t^2/2}$ with $\gamma =$ width. Gaussian lines (standard deviation $\gamma$); requires $\gamma T \gg 1$.

With the same width, the result agrees with autocorrelation_spectrum(c, ε, ω; width, lineshape). The cost is $O(N_t N_\omega)$.

Pauli–Fierz Hamiltonian (v0.2.0)

FEMTISE.pauli_fierz_potential — Method
pauli_fierz_potential(matter_potential, dipole; frequency, coupling,
                      dipole_self_energy = true)

Potential energy of the Pauli–Fierz Hamiltonian (length gauge, dipole approximation) for matter coupled to one cavity mode, as a function of the mesh point $\mathbf{x} = (x_1, \dots, x_{d-1}, q)$, whose last coordinate is the photon displacement $q$:

\[V(\mathbf{x}) = V_{\rm matter}(\mathbf{r}) + \frac{\omega^2 q^2}{2} + g\sqrt{2\omega}\, q\, d(\mathbf{r}) + \frac{g^2}{\omega}\, d(\mathbf{r})^2, \qquad \mathbf{r} = (x_1,\dots,x_{d-1}).\]

Arguments

  • matter_potential(r), dipole(r): functions of the matter coordinates r = (x₁, …) (a tuple), in atomic units. For an electron at $z$ and a nucleus of charge $Z$ at $R$, the dipole is $d = ZR - z$.
  • frequency: cavity frequency $\omega$.
  • coupling: light–matter coupling $g$ (a.u.).
  • dipole_self_energy: include the term $(g^2/\omega)\,d^2$ (default). Omitting it makes the Hamiltonian unbounded from below for large couplings.

The photon coordinate has unit mass: pass masses (M₁, …, 1.0) to solve_tise.

Example: nucleus–electron–photon

V_matter(r) = my_molecular_potential(r[1], r[2])   # user function, r = (R, z)
d(r) = r[1] - r[2]                              # Z = 1
V = pauli_fierz_potential(V_matter, d; frequency = 0.1, coupling = 0.01)
model = CartesianDiscreteModel((0.5, 6.0, -8.0, 8.0, -20.0, 20.0), (30, 40, 40))
sol = solve_tise(model, V; masses = (918.0, 1.0, 1.0), nev = 6, sigma = -1.0)

FEMTISE.plot_energy_map — Function
plot_energy_map(λ, μ, energies; level = 1, gap = nothing,
                labels = ("First parameter, λ", "Second parameter, μ"),
                energy_label = nothing, colormap = :inferno, contours = 8,

Two-dimensional map of an eigenvalue over two parameters, from a two-parameter sweep (energies[n, i, j] for λ[i], μ[j]):

  • gap = nothing: the eigenvalue energies[level, :, :];

The map uses a perceptually uniform colour map with monotonic lightness and contours level lines (black over a white halo, visible on any background), so that it remains readable in black and white.

Requires a Makie backend: using CairoMakie. Returns a Makie.Figure.
